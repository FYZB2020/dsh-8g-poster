# 印前自检清单

交付前逐条打勾，任一条不过不要交付。

## 尺寸与分辨率
- [ ] PDF 页面尺寸与实物完全一致（2m×1m 就是 2000×1000 mm，不是 A 系列比例缩放）
- [ ] 位图尺寸 / 物理尺寸 = 有效 dpi，大幅面展板 ≥ 72dpi 可接受，≥ 100dpi 更稳
- [ ] 素材（二维码、logo）为原生分辨率贴入，不是从放大后的底图里截的
- [ ] 四周出血 3mm 说明已写清，深色区补深色、浅色区补底色

## 可读性
- [ ] 最小正文字号实物 ≥ 12mm（2m 展板 / 3m 视距）；主标题 ≥ 50mm
- [ ] 深字浅底或浅字深底，没有低对比度组合（金色小字压在米白底上是大忌）
- [ ] 3 秒内能读完主标题；信息层级不超过 3 层
- [ ] 缩到手机屏幕大小（约 1/10）仍能认出主标题与分组

## 二维码（有码时）
- [ ] 实物边长 ≥ 80mm（越大越好，展板场景 100mm+ 更稳）
- [ ] 静区 4 模块完整，四周没有压字、压线、压图
- [ ] 相邻码间距足够，互不侵占静区
- [ ] 每个码下方标签与其内容一一对应（尤其同名不同学段）
- [ ] `verify_qr.py` 逐码 PASS，URL 与源逐字一致
- [ ] 纠错等级 H，中心嵌 logo 面积 ≤ 20%

## 版面
- [ ] 无元素越界、无文字被裁、无贴图压字
- [ ] 卡片/分组边距一致，同层级元素对齐
- [ ] 没有整片空场（宣传物料尤其忌讳，会显得字小）

## 文案
- [ ] 逐字核对，重点查同音错字（看/是、中/印）
- [ ] 无禁用词、无未授权承诺、无错误电话与联系人
- [ ] 机构名、背书表述与官方口径一致

## 字体与合规
- [ ] 商用字体已授权，或已换思源黑体/阿里巴巴普惠体/站酷系列
- [ ] 图片素材有商用授权，人物肖像已获授权
- [ ] AI 生成内容按平台要求处理标识与水印

## 交付物
- [ ] 原尺寸 PNG（无损）
- [ ] 印刷 PDF（页面尺寸精确）
- [ ] 预览图（1600px 宽，方便微信传阅）
- [ ] 印前说明（尺寸、色值、出血、材质、字体授权提示）
